## Agile Workflow Demonstration

This repository demonstrates version-control practices
for the Online Grocery Application jury.

### Workflow
- Backlog: User stories and acceptance criteria
- To Do: Work not yet started
- In Progress: Work currently being performed
- Testing: Work awaiting verification
- Done: Work meeting the agreed Definition of Done

### Version Control
- Main branch: Stable baseline
- Feature branch: Isolated changes
- Pull request: Review before merging

### Project Status
This repository demonstrates Agile practices.
It does not claim that a functional grocery application
or automated test suite has been implemented.
